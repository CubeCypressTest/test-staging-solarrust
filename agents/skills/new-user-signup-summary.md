---
title: "New User Signup Summary"
description: "Use when the user asks about new user signups, user acquisition trends, registration counts, or new customer growth."
---

Produce a new user signup summary:

1. Report the total number of new user signups for the requested period alongside the previous equivalent period and the percentage change.
2. Show a daily or weekly breakdown of signups as a trend (use weekly buckets for periods longer than 30 days, daily otherwise).
3. Break down signups by city or region if that dimension is available.
4. Identify the single day or week with the highest signup count and highlight it.
5. If the user specifies a time range or geographic filter, apply it; otherwise default to the last 30 days.
