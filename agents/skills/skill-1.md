---
title: "New User Signup Summary"
description: "Use when the user asks about new user signups, user acquisition trends, registration counts, or new customer growth."
---

Produce a new user signup summary:

1. First, determine the last available date in the dataset.
2. Report the total number of new user signups for the requested period alongside the previous equivalent period and the percentage change.
3. Show a daily or weekly breakdown of signups as a trend (use weekly buckets for periods longer than 30 days, daily otherwise).
4. Break down signups by city or region if that dimension is available.
5. Identify the single day or week with the highest signup count and highlight it.
6. If the user specifies a time range or geographic filter, apply it; otherwise use the last available period in the data (default to the last available month).
